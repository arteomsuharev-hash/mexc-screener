MEXC Screener — десктоп-приложение (Windows)
=============================================

КАК ЗАПУСТИТЬ
1. Распакуйте весь архив в одну папку (MEXC-Screener.exe и start.bat
   должны лежать РЯДОМ, в одной папке).
2. Запустите файл "start.bat" (двойной клик).
   Он снимет блокировку Windows (Mark of the Web) с MEXC-Screener.exe
   и сразу откроет приложение.
3. В следующий раз можно открывать MEXC-Screener.exe напрямую — блокировка
   снимается один раз и не возвращается.

ПОЧЕМУ ВООБЩЕ ЕСТЬ БЛОКИРОВКА
Windows блокирует запуск ЛЮБОГО .exe-файла, скачанного из интернета, если
у него нет платной цифровой подписи от известного издателя (это касается
не только этой программы — так работает любой независимый софт).
"start.bat" просто автоматически делает то же самое, что вручную
делается через:
  Свойства файла → вкладка "Общие" → галочка "Разблокировать" → ОК

ЕСЛИ .bat ТОЖЕ НЕ ЗАПУСКАЕТСЯ
Разблокируйте вручную: правой кнопкой по MEXC-Screener.exe → Свойства →
внизу вкладки "Общие" поставьте галочку "Разблокировать" → Применить → ОК.
