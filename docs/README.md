# История проекта (журнал по раундам)

Каждый файл — это то, что менялось в приложении за один раунд правок, почему, и как это было
проверено. Читать по порядку, если нужен полный контекст; если нужен только конкретный вопрос —
искать по ключевым словам (grep) внутри `docs/`, ссылки на функции/переменные приведены везде
верно на момент соответствующего раунда (более поздние раунды переименовывают/удаляют часть кода —
там, где это важно, оставлены пометки "Обновление раунда N").

- `00-notes.md` — сквозные заметки проекта: открытые задачи, решённые баги подключения к API,
  архитектурные ограничения (лимит WS-потоков MEXC), пайплайн сборки desktop-приложения,
  интеграция с Vataga.Terminal (не завершена).
- `04-round4.md` — сортировка внутри стратегий, первая версия "своего графика" (запасной канделстик
  для пар без TradingView), адаптивность под размер окна, PnL-график, критический баг сборки
  (забытый тег `neutralino.js`).
- `05-round5.md` — "свой график" на уровне TradingView: панель объёма, MA7/25, типы графика,
  вотермарк, легенда OHLC.
- `06-round6.md` — фикс ленты сделок, лучи/прямые линии на графике, дашборд баланса с анимациями,
  полировка главной таблицы.
- `07-round7.md` — откат мигания цены, TV-стиль тулбара графика, календарь P&L по дням, журнал
  сделок (точки входа/выхода).
- `08-round8.md` — новая страница «Финрез» (5 вкладок) 1:1 по референс-скриншоту, перенос аналитики
  баланса со страницы аккаунта.
- `09-round9.md` — баланс полностью переехал на «Финрез» (устранено дублирование), переработка
  анимаций без "мигания" при автообновлении, редизайн календаря под читаемость.
- `10-round10.md` — редизайн «Финрез» под тёмную trading-terminal палитру по референсу, реальные
  показатели на вкладках P&L/Риски/Сделки/Активы.
- `11-round11.md` — реальный (не только текущий баланс) список монет в журнале сделок: постоянная
  память символов + поиск по всему рынку MEXC.
- `12-round12.md` — читаемость календаря (два последовательных бага), редизайн ячеек, надёжность
  "Сделок"/"Рисков", точность стратегий (`STRATEGY_MIN_LIQUID_VOL24`) + краткое описание алгоритма
  в UI.
- `13-round13.md` — Финрез в реальном времени (visibility/focus-хендлеры), точность стратегий
  (фильтр подтверждения пробоя), честная оценка большого 26-этапного ТЗ (что реализуемо, что нет и
  почему — лимит WS-потоков MEXC).
- `14-round14.md` — динамическое объяснение алгоритма по конкретной монете, кнопка "Обновить" +
  настоящий фикс permanent-freeze бага Финреза, попытка встроить страницу MEXC в iframe и её откат
  по эмпирическому доказательству блокировки, разбивка проекта на файлы (этот репозиторий).

## Сквозные технические темы, если ищете что-то конкретное

- **Пайплайн сборки desktop-версии**: `00-notes.md` (историческая версия) → `14-round14.md` (текущая,
  актуальная — см. также `desktop/build.sh` в корне репозитория).
- **Финрез — обновление в реальном времени / зависания**: `13-round13.md` (эвристика по видимости
  окна) → `14-round14.md`, пункт B (настоящий фикс promise-lock).
- **Точность стратегий (Алгоритмы/Неэффективности/Пробой плотностей)**: `12-round12.md` (пол
  ликвидности) → `13-round13.md` (фильтр подтверждения пробоя) → `14-round14.md`, пункт A
  (объяснение по конкретной монете).
- **График монеты**: `04-round4.md` (первая версия "своего графика") → `05-round5.md` (TradingView-
  уровень) → `07-round7.md` (TV-стиль тулбара) → `14-round14.md`, пункт D (попытка встроить реальную
  страницу MEXC и откат).
- **Раздел «Финрез»**: `08-round8.md` (создание) → `09-round9.md` (перенос баланса, анимации) →
  `10-round10.md` (палитра, показатели) → `11-round11.md` (полный список монет) → `12-round12.md` /
  `13-round13.md` / `14-round14.md` (баги и полировка).
