Сюда кладёшь свои картинки. Три слота, три имени файла — код ищет их
ровно по этим именам. PNG или GIF (анимированный) — как удобнее, просто
назови файл с нужным расширением. Если положишь ОБА — покажется GIF,
PNG останется про запас (например, если понадобится вернуться к статике,
достаточно удалить .gif).

1) sidebar.png / sidebar.gif — фон левой панели (сайдбара)
   - вертикальная (портретная) ориентация — сайдбар узкий (~248px) и высокий
   - минимум 600x1400px, чтобы не мылилось
   - поверх лежит затемняющий градиент (снизу темнее, чем сверху),
     чтобы пункты меню оставались читаемыми

2) chart-placeholder.png / chart-placeholder.gif — фон пустого экрана
   графика («Выберите монету для графика MEXC»), справа
   - вертикальная (портретная) ориентация — колонка узкая (~320px) и
     высокая (430px+, растягивается по высоте окна)
   - минимум 700x1000px, чтобы не мылилось
   - поверх лежит виньетка (темнее по краям, светлее в центре)

3) finres-hero.png / finres-hero.gif — баннер в самом верху страницы «Финрез»
   - широкая горизонтальная (баннер) почти во всю ширину окна (без сайдбара),
     но невысокая — минимум 1600x320px
   - поверх лежит затемнение по бокам, светлее в центре — баннер виден
     всегда, даже без подключённого API-ключа

Нет файла ни в одном формате — экран выглядит как раньше, ничего не
ломается.

Про GIF отдельно: имей в виду вес файла — большая анимированная картинка
может весить несколько МБ и раздует итоговый exe на столько же (он
собирается со всеми картинками внутри). Ужимай, если начнёт тормозить
сборку/запуск.

После того как положишь файл(ы) — скажи мне, и я пересоберу приложение
(файлы подхватываются только при пересборке, не на лету).
